# IBM Plex Sans

Unmodified Regular, Medium and SemiBold WOFF2 files from the
[IBM Plex repository](https://github.com/IBM/plex/tree/master/packages/plex-sans/fonts/complete/woff2).
Copyright 2017 IBM Corp., with Reserved Font Name "Plex". Distributed under the
[SIL Open Font License 1.1](OFL.txt). The full required notice is retained.

The application self-hosts these three weights. It does not contact an external
font service at runtime.
